# Yatha App

Aplicación móvil para gestión de cobros y seguimiento de préstamos.

## 🚀 Características

- **Autenticación de Usuarios**
  - Login para gestores y supervisores
  - Gestión de sesiones segura

- **Panel de Gestor**
  - Dashboard con métricas clave
  - Lista de préstamos asignados
  - Detalles de cada préstamo
  - Registro de cobros
  - Seguimiento de rendimiento

- **Panel de Supervisor**
  - Vista general de todos los gestores
  - Métricas de rendimiento por gestor
  - Gráficos de progreso
  - Detalles individuales de gestores

- **Diseño Moderno**
  - Interfaz de usuario intuitiva
  - Tema personalizado con Material Design 3
  - Componentes de vidrio (glassmorphism)
  - Diseño responsivo

## 🛠️ Tecnologías

- **Flutter** - Framework de desarrollo móvil
- **Dart** - Lenguaje de programación
- **Material Design 3** - Sistema de diseño
- **Google Fonts** - Tipografía personalizada
- **Fl Chart** - Gráficos y visualizaciones

## 📋 Requisitos

- Flutter SDK (última versión estable)
- Dart SDK (última versión estable)
- Android Studio / VS Code
- Dispositivo Android o iOS para pruebas

## 🔧 Instalación

1. Clonar el repositorio:
```bash
git clone https://github.com/tu-usuario/yatha_app.git
```

2. Instalar dependencias:
```bash
cd yatha_app
flutter pub get
```

3. Ejecutar la aplicación:
```bash
flutter run
```
